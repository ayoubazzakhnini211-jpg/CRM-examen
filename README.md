# CRM examen

Mini CRM Full Stack : gestion de clients.

- `front/` : interface HTML, CSS, JavaScript
- `back/` : serveur Node.js (Express) + MongoDB (Mongoose)

## Lancer en local
```bash
cd back
cp .env.example .env   # puis renseigner MONGODB_URI
npm install
npm start              # http://localhost:3000
```
